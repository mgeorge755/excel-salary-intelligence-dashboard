
# Salary Intelligence Dashboard | Excel Data Analytics Project

![Salary Intelligence Dashboard](dashboard.png?v=2)
## Project Overview

Developed an interactive Excel dashboard analyzing 22,002 data-related job postings to identify salary trends, hiring patterns, and compensation differences across job roles, countries, and remote work arrangements.

The objective was to transform raw job market data into actionable insights using Excel.

## Tools & Skills

- Microsoft Excel
- Data Cleaning & Validation
- PivotTables & PivotCharts
- Interactive Slicers
- XLOOKUP, FILTER, MEDIAN, COUNTIFS, and GETPIVOTDATA
- Descriptive Statistics
- Data Visualization
- Dashboard Development

## Dashboard Features

- **Total Jobs:** Dynamic count of job postings
- **Average Salary:** Average compensation based on selected filters
- **Median Salary:** Custom interactive median calculation
- **Salary by Job Role:** Comparison of average salaries across data professions
- **Remote vs Non-Remote:** Analysis of compensation differences
- **Monthly Hiring Trends:** Job posting volume and salary trends throughout 2023
- **Interactive Filters:** Country and Job Role slicers

## Key Findings

### 1. Senior Data Scientists Earn the Highest Average Salaries

Senior Data Scientists recorded an average annual salary of $154,206 across 1,690 job postings, with a median salary of $155,500.

The relatively small difference between the mean and median suggests limited overall salary skewness for this role.

### 2. Remote Jobs Offer Higher Average Salaries

Remote positions averaged $131,615 annually, compared with $121,830 for non-remote positions.

This represents an approximately 8% salary premium. However, this relationship is observational and does not establish causation.

### 3. Higher Salaries Pull the Overall Average Upward

Across 22,002 postings:

- Average Salary: $123,288
- Median Salary: $115,000

The higher mean suggests a right-skewed salary distribution, where high-paying positions increase the overall average.

### 4. Hiring Activity Declined Toward the End of 2023

Job posting volumes decreased toward the end of 2023, while average salaries remained relatively stable or fluctuated.

One possible explanation is a changing mix of entry-level and experienced positions. Further analysis would be required to confirm this hypothesis.

## Project Methodology

1. Cleaned and validated the original dataset.
2. Standardized salary values and posting dates.
3. Calculated descriptive statistics and salary distributions.
4. Analyzed compensation across job roles, countries, and remote work arrangements.
5. Created PivotTables and PivotCharts to summarize the data.
6. Built an interactive dashboard using slicers and dynamic KPIs.
7. Validated calculations and documented key findings.

## Data Limitations

- Job postings do not necessarily represent actual salaries paid.
- Some countries and job roles have small sample sizes.
- Salary differences may reflect seniority, experience, location, or employer characteristics.
- Observed relationships should not be interpreted as causal effects.
